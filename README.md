# site

Minimalist Academic & Software Engineering Portfolio for **Arafat Iqbal**.

Built with [Next.js](https://nextjs.org/) (App Router, static export), TypeScript, and [Tailwind CSS](https://tailwindcss.com/). Hosted on [GitHub Pages](https://sharafat397.github.io/site/).

## 🚀 Live Demo
🔗 **[https://sharafat397.github.io/site/](https://sharafat397.github.io/site/)**

## 📂 Features
- **Minimalist Aesthetic:** Clean typography, monochrome accents, accessible contrast, responsive dark/light mode.
- **Publications & Preprints:** Detailed research manuscripts with abstracts, focus tags, and links.
- **Engineering Experience:** Software engineering positions, achievements, and impact.
- **Featured Projects:** Production apps, ERPs, microservices, and machine learning models.
- **Curriculum Vitae:** Direct download link for `arafat_cv.pdf`.
- **Static Export & GitHub Actions:** Fully automated build and deployment to GitHub Pages on every push to `main`.

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the site locally.

## 📦 Build & Export

```bash
# Build static site to ./out directory
npm run build
```
